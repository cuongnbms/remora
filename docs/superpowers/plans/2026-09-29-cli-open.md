# Open a Folder from the Command Line Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `remora [folder]` opens a local folder in Remora; a folder that is not already a project lands in a persisted **Opened** section at the bottom of the sidebar.

**Architecture:** A bundled sh script runs `open -a Remora <dir>`; macOS delivers it to the app as `RunEvent::Opened`. Rust queues the folder and signals the frontend, which drains the queue and applies a pure `openLocalFolder` config op (select an existing local project, or add to `config.opened`). `opened` is a new top-level config list that every project lookup already walks.

**Tech Stack:** Tauri 2 (Rust), React 19 + zustand, vitest, POSIX sh, mise.

**Spec:** `docs/superpowers/specs/2026-09-29-cli-open-design.md`

## Global Constraints

- Config fields: TS `opened?: Project[]`, `openedCollapsed?: boolean`; Rust `opened: Vec<Project>`, `opened_collapsed: bool`, serialized camelCase, both `#[serde(default)]` and left out of the JSON when empty / false.
- TS config ops never add an `opened` key to a config that lacks one (a config with no `opened` stays without the key).
- Order: `opened` is newest first, never sorted (not by `sortByName`, not by the Order setting). In every flat project list (`Config::projects()`, `flatProjects`) opened projects come **after** all groups.
- Folder path normalization, one rule everywhere: strip trailing `/` characters, except that `/` itself stays `/`. TS: `normalizeFolderPath` in `src/lib/configOps.ts`. Rust: inside `folders_from_urls`.
- A new opened project is `{ id: newId(), name: <last path segment, or "/" for root>, host: LOCAL_HOST, path }`, no `bookmarked` key.
- Event name `open-folders`, no payload. Command `take_pending_opens() -> Vec<String>`. The queue is the only channel for paths.
- Section label text is exactly `Opened`; section element `<section className="opened">`, label `<div className="opened-label[ open]">`.
- CLI error copy: `remora: not a folder: <arg>` (exit 1); `usage: remora [folder]` (exit 2).
- Test commands: `pnpm test` (frontend), `cargo test --manifest-path src-tauri/Cargo.toml` (Rust). Both must pass before every commit.
- Commits: Conventional Commits with the repo's scopes (`feat(cli):`, `feat(config):`, `feat(sidebar):`, `docs(readme):`, `build(mise):`).

## Review Focus

- Folder names with spaces or non-ASCII (`Kế hoạch dự án`): the file URL is percent-encoded, and the project must get the decoded path and name. Pinned in Task 1 and Task 3 tests.
- Opening a folder while Remora is not running: the path must survive until the frontend is ready. Pinned by the builder-managed queue (Task 1) and the manual cold-start check (Task 6).
- The same folder opened again, with or without a trailing slash: no duplicate row. Pinned in Task 3.
- An opened project that is bookmarked and then moved into a group keeps its bookmark. Pinned in Task 3.
- A config with no `opened` key must round-trip unchanged (old configs, and saves that never touch Opened). Pinned in Task 2 and Task 3.

- [ ] **Step 1: Write the script** (exact copy)

```sh
#!/bin/sh
# Open a folder in Remora, like `code .`: remora [folder]   (default: the current folder)
set -eu
if [ "$#" -gt 1 ]; then
  echo "usage: remora [folder]" >&2
  exit 2
fi
dir=${1:-.}
if [ ! -d "$dir" ]; then
  echo "remora: not a folder: $dir" >&2
  exit 1
fi
exec open -a Remora "$(cd "$dir" && pwd -P)"
```
